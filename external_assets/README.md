# Optional low-poly source

The mockup's default island and plant are procedural meshes generated by
`MockupProjectBuilder`, which keeps the first CI run small and deterministic.

For a later art pass, download the **Kenney Nature Kit** from:

https://kenney.nl/assets/nature-kit

License: **CC0 1.0** (as stated by Kenney on the asset page). Import rock,
tree, or bush models beneath:

```text
Assets/Art/External/KenneyNatureKit/
```

Then replace the generated `RewardPlant` child in
`MockupProjectBuilder.CreateWorld` while retaining the procedural fallback for
headless or offline CI. The builder already looks for `tree_default.fbx` and
`plant_bush.fbx` at that location and instantiates them when imported. Do not
check credentials or private asset-store files into the repository.
