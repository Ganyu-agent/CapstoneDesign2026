# CapstoneDesign2026 Unity Mockup

This branch contains the first Unity 6 URP mockup for the CapstoneDesign2026
vertical slice. The scene is generated by Unity Editor automation so the
serialized scene and prefab YAML files are not hand-authored.

The mockup is intentionally calm and low pressure, following the 2026-09-11
meeting direction: a gentle entry for people in recovery, no competition or
ranking, daily activities that nourish a plant, and visual rewards that make
progress feel tangible. It uses a floating low-poly island as the first visual
reward surface.

## Generate the project scene

The repository contains the Unity project skeleton. After Unity 6.3.24f1 is
available, run:

```bash
./scripts/bootstrap-project.sh
```

That command calls `CapstoneDesign.EditorTools.MockupProjectBuilder.BuildMockup`,
which creates the URP pipeline asset, procedural low-poly meshes and materials,
the main scene, the navigation UI, and the sensor overlay.

## Build and visual preview

```bash
./scripts/test.sh
./scripts/visual-preview.sh
./scripts/build-android.sh
```

`visual-preview.sh` deliberately omits `-nographics`; it expects the worker's
Xvfb display and Intel Vulkan device selection from `/etc/profile.d`.

## A7 hardware smoke test

The A7 can stay offline without blocking the fast path. Set `ADB_SERIAL` to the
authenticated wireless serial when it is available:

```bash
ADB_SERIAL=192.168.0.222:5555 ./scripts/test-a7.sh
```

The script installs the APK, launches the mockup, collects a screenshot and
logcat, and optionally records a short video with `A7_SCREENRECORD=1`.

Unity account authentication, Android SDK license acceptance, GitHub account
authentication, and device approval are intentionally runtime/operator steps.
